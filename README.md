# Project overview
Goal: Implement a linear regression model to predict house prices.

Inputs (features): square footage of the house, number of bedrooms, number of bathrooms.

Output (target): predicted selling price of the house.
​


# Dataset
train.csv: Training data with features and target price.
​
test.csv: Test data without target price, used for final predictions.
​
data_description.txt: Text description of each column in the dataset.

sample_submission.csv: Example file showing the required submission format.
​


# Project structure
task1.ipynb: Main notebook with EDA, model training, evaluation, and prediction steps.

train.csv: Training data.
​
test.csv: Test data for making predictions.
​
sample_submission.csv: Template for submission file.
​
submission.csv: Final predictions generated by the model.
​
data_description.txt: Column definitions and additional details.
​


# Approach
Load and inspect the dataset (missing values, data types, basic statistics).
​
Perform EDA: distributions of square footage, bedrooms, bathrooms; relationships with price using scatter plots and correlation.
​
Pre‑process data: handle missing values, encode any categorical features, split features and target.​

Build a baseline linear model using scikit‑learn LinearRegression (optionally Ridge/Lasso).​

Train and evaluate using a train/validation split or cross‑validation with MAE, MSE, or RMSE.​

Optionally improve with feature scaling, regularization, and basic feature engineering.
​
Generate predictions for test.csv and save them to submission.csv in the required format.
​
